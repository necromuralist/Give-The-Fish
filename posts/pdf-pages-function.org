* The Function Declaration

#+begin_src fish :noweb-ref pdfpages-declaration
function pdfpages -d "Extract pages from a pdf" --argument-names source_pdf target_pdf pages
#+end_src

* The Command Call

This uses qpdf ([[https://github.com/qpdf/qpdf][GitHub Repsitory]]) to extract pages from a PDF. It's a function not an abbreviation because you intersperse your arguments within their syntax, rather than just pasting it all after the call.

#+begin_src fish :noweb-ref pdfpages-body
qpdf --empty --pages $source_pdf $pages -- $target_pdf
#+end_src

* Error Handling

#+begin_src fish :noweb-ref pdfpages-error
if test $status -ne 0
    echo "source_pdf = $source_pdf"
    echo "target_pdf = $target_pdf"
    echo "pages = $pages"
end
